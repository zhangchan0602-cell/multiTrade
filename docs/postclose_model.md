# A股短线多因子-盘后版执行模型（v2.1）

> 适用风格：偏交易执行的短线轮动
>
> 更新日期：2026-05-13

## 1. 模型目标

在保证可执行性的前提下，从全A（不含科创板）中筛出短线刚启动、量价同步、波动可控的候选标的。

v2 的核心变化：真实日线 OHLCV 优先，预筛只剔除明显不可交易样本，最终评分尽量使用完整 20 日量价结构，而不是只依赖当日行情代理。

## 2. 股票池与硬过滤

- 股票池：沪A主板 + 深A主板 + 创业板（不含科创板）
- 剔除 `ST/*ST`
- 上市满 `60` 个交易日
- 近 `20` 个交易日日均成交额不低于 `1亿`
- 收盘价不低于 `3元`
- 近 `20` 日平均换手率在 `1% ~ 20%`

K 线抓取前使用宽松预筛：上市约满 `45` 个自然日、当日成交额不低于 `3000万`、价格不低于 `2元`、当日换手率在 `0.2% ~ 35%`。宽松预筛只用于减少接口请求，最终入选仍以真实 K 线硬过滤为准。

当未显式指定 `SHORT_KLINE_CANDIDATE_LIMIT` 时，脚本会按宽松预筛通过样本的约 `20%` 动态确定 K 线抓取规模，并限制在 `600 ~ 900` 之间，以在覆盖率与接口成功率之间做平衡。

## 3. 因子结构

- 启动 `32%`
  - 3日收益率
  - 5日收益率
  - 启动加速度（近5日涨幅 − 前15日涨幅）
  - 20日新高突破
  - 20日区间收盘位置
  - 站上20日均线幅度
  - 近5日收盘强度

- 趋势 `23%`
  - 10日收益率
  - 20日收益率
  - 20日均线突破
  - 5/10/20日均线排列
  - 20日价格斜率
  - 趋势效率（20日收益 / 20日绝对波动路径）

- 活跃 `20%`
  - 1日/20日成交额放大比
  - 3日/20日成交额放大比
  - 5日/20日成交额放大比
  - 5日平均换手率
  - 5日/20日换手加速度

- 稳定 `17%`
  - 10日波动率（取负）
  - 20日波动率（取负）
  - 20日下行波动率（取负）
  - 20日最大回撤
  - 20日上涨胜率
  - 底部收益波动收敛度
  - 底部日内振幅收敛度
  - 近5日上影线压力（取负）

- 流动 `8%`
  - 20日均成交额
  - 20日平均换手率

## 4. 打分方式

每个原始因子按以下步骤处理：

1. 双侧 `2.5%` 去极值
2. 行业内 `z-score`，行业样本不足 `3` 只时退化为全市场 `z-score`
3. 先在通过硬过滤的真实 K 线样本上合成启动、趋势、活跃、稳定、流动五组分
4. 按组权重合成总分
5. 排序后再叠加次日 `2~3` 天交易过滤与动量地板，避免纯成交活跃但启动不充分的标的进入最终 Top5

当 K 线接口不可用时，脚本默认优先要求真实 K 线；若最终真实 K 线样本为空，则退回到纯行情降级候选，并在输出中标记 `quote_only_fallback_used`。该结果只适合临时观察，实盘优先级低于真实 K 线样本。

## 6. 说明

- 该模型偏执行层，主要使用价格、成交额、换手、突破位置、均线结构与波动收敛特征
- 不依赖滞后的财报因子，更适合短线候选池更新
- 仅用于量化研究与策略开发讨论，不构成投资建议
