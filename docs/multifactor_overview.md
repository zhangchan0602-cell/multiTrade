# 短线多因子模型概览

> 版本：v2.2  
> 更新：2026-05-15  
> 适用脚本：`scripts/short_screen.py`（含盘后版与尾盘版）

---

## 一、模型定位与目标

本模型面向 **A 股短线轮动**（T+0 入场、T+2~T+3 出场），核心逻辑：

1. 从全 A（不含科创板）约 4500+ 只股票中每日筛出 **"刚启动 + 量价同步 + 波动可控"** 的前 20 候选
2. 再叠加交易执行过滤，最终输出 Top5 作为实盘操作参考

模型分两个运行模式：

| 模式 | 运行时间 | 持仓目标 | 输出前缀 |
|------|---------|---------|---------|
| **盘后版** | 15:30 收盘后 | 次日入场，持有 2~3 个交易日 | `short_` |
| **尾盘版** | 14:30~14:45 | 当日 14:50 入场，参考持有至次日 | `tail_` |

## 二、股票池与硬过滤

### 2.1 股票池

- 沪 A 主板 + 深 A 主板 + 创业板
- **排除**：科创板（688xxx）、北交所

### 2.2 硬过滤条件（基于真实 K 线）

| 条件 | 阈值 |
|------|------|
| 剔除 ST / \*ST | 名称含 `ST` 全部排除 |
| 上市年龄 | K 线记录 ≥ 60 个交易日 |
| 20 日均成交额 | ≥ 1 亿元 |
| 收盘价 | ≥ 3 元 |
| 20 日平均换手率 | 1% ~ 20% |

### 2.3 K 线候选宽松预筛（仅减少接口调用）

| 条件 | 阈值 |
|------|------|
| 上市自然日 | ≥ 45 天 |
| 当日成交额 | ≥ 3000 万 |
| 收盘价 | ≥ 2 元 |
| 当日换手率 | 0.2% ~ 35% |

动态候选规模 = `宽松预筛通过数 × 20%`，限制在 `600 ~ 900` 之间。

## 三、原始因子

数据来源：日线后复权 OHLCV（至少需 25 根，主要使用近 60 根）。

### 3.1 启动类（Launch）

| 因子 | 公式 | 含义 |
|------|------|------|
| `ret_3` | `close[-1] / close[-4] - 1` | 3 日涨幅 |
| `ret_5` | `close[-1] / close[-6] - 1` | 5 日涨幅 |
| `accel` | `ret_5 - (close[-6] / close[-21] - 1)` | 近5日 vs 前15日涨幅差，正值表示刚启动 |
| `high_breakout_20` | `close[-1] / max(high[-21:-1]) - 1` | 突破前20日最高价幅度 |
| `close_position_20` | `(close[-1] - min(low[-20:])) / (max(high[-20:]) - min(low[-20:]))` | 收盘价在20日区间内的位置 |
| `price_vs_ma20` | `MA5 / MA20 - 1` | 短期均线对中期均线偏离度（与 breakout_20 来源不同，避免重复） |
| `close_strength_5` | `mean((close - low) / (high - low), 近5日)` | 近5日收盘强度 |

### 3.2 趋势类（Trend）

| 因子 | 公式 | 含义 |
|------|------|------|
| `ret_10` | `close[-1] / close[-11] - 1` | 10 日涨幅 |
| `ret_20` | `close[-1] / close[-21] - 1` | 20 日涨幅 |
| `breakout_20` | `close[-1] / MA20 - 1` | 收盘价突破 MA20 幅度 |
| `ma_alignment_20` | `0.6 × (MA5/MA20-1) + 0.4 × (MA10/MA20-1)` | 均线多头排列强度 |
| `ma_bull_20_60` | `MA20 / MA60 - 1` | 20日均线对60日均线偏离（中长期趋势） |
| `trend_slope_20` | 近20日收盘价线性回归斜率 / 近20日均值 | 趋势斜率（归一化） |
| `trend_efficiency_20` | `ret_20 / sum(abs(daily_ret[-20:]))` | 趋势效率，排除震荡路径损耗 |

### 3.3 活跃类（Activity）

| 因子 | 公式 | 含义 |
|------|------|------|
| `amount_ratio_1_20` | `amount[-1] / mean(amount[-20:])` | 当日成交额放大比 |
| `amount_ratio_3_20` | `mean(amount[-3:]) / mean(amount[-20:])` | 3日成交额放大比 |
| `amount_ratio_5_20` | `mean(amount[-5:]) / mean(amount[-20:])` | 5日成交额放大比 |
| `turnover_5` | `mean(turnover[-5:])` | 5日平均换手率 |
| `turnover_accel_5_20` | `mean(turnover[-5:]) / mean(turnover[-20:]) - 1` | 换手率近期加速度 |
| `volume_ratio` | 当日量 / 5日均量（实时行情字段） | 实时量能爆发强度 |
| `money_flow_bias_20` | `(上涨日成交额合计 - 下跌日成交额合计) / 总成交额，近20日` | 资金净流入偏向 |
| `price_volume_sync_10` | `corr(daily_ret[-10:], amount_change[-10:])` | 近10日价量相关性 |

### 3.4 稳定类（Stability，越低越好的取负）

| 因子 | 方向 | 含义 |
|------|------|------|
| `vol_10` | 取负 | 近10日日收益标准差 |
| `vol_20` | 取负 | 近20日日收益标准差 |
| `downside_vol_20` | 取负 | 近20日下行日收益标准差 |
| `max_drawdown_20` | 原值（负数，越大越好） | 近20日最大回撤 |
| `win_rate_20` | 正向 | 近20日上涨天数比率 |
| `chip_tightness_20` | 正向（内部已取负） | 底部横盘期（day-20~day-5）日收益波动+日内振幅的加权负值，越大说明筹码越集中 |
| `upper_shadow_5` | 取负 | 近5日上影线比例，越大说明压力越重 |

底部收敛度：`chip_tightness_20 = -( 0.6 × vol_base + 0.4 × range_base )`  
其中 `vol_base = std(daily_ret[-20:-5])`，`range_base = mean(high/low - 1, [-20:-5])`

### 3.5 流动类（Liquidity）

| 因子 | 公式 |
|------|------|
| `avg_amount_20` | `mean(amount[-20:])`，20 日均成交额 |
| `turnover_20` | `mean(turnover[-20:])`，20 日平均换手率 |

## 四、标准化处理

每个原始因子依次：

1. **去极值**：双侧 2.5% Winsorize（替换为第 2.5 / 97.5 百分位值）
2. **行业内 z-score**：按申万一级行业分组，`z = (x - μ) / σ`；样本 < 3 只时退化为全市场 z-score；inf / NaN 填 0

### 5.2 尾盘版权重（`[tail]`）——与盘后版的核心差异

尾盘版偏重"当日刚启动"与当日量能爆发，降低长期趋势权重。

| 维度 | 盘后版总权重 | 尾盘版总权重 | 变化 |
|------|-----------|-----------|------|
| 启动（launch） | 22% | **28%** | ↑ |
| 趋势（trend） | 25% | **18%** | ↓ |
| 活跃（activity） | 23% | **34%** | ↑↑ |
| 稳定（stability） | 24% | 14% | ↓ |
| 流动（liquidity） | 6% | 6% | = |

动量分内部：`launch:trend = 0.68:0.32`（盘后版为 0.56:0.44），更强调短线冲量。

活跃分中 `amount_ratio_1_20` 权重由 0.10 → **0.20**，强调当日量能爆发。

## 六、交易执行过滤条件

打分排序后叠加七项过滤，全部通过才进入最终候选，最后输出字段 `pass_next_2_3d_setup = true`。

另加执行地板：`momentum_score > 0` 且 `launch_score > -0.10`（盘后）/ `> 0.02`（尾盘），排除纯流动性驱动但启动不足的标的。

### 盘后版过滤阈值

| 过滤项 | 条件 |
|--------|------|
| 当日行情 | change_rate ∈ [-4%, 9.8%] 且 amp ≤ 16% |
| 启动窗口 | ret_3 ∈ [-2%, 12%]，ret_5 ∈ [-1%, 18%]，ret_20 ∈ [-8%, 35%]，accel ≥ -5% |
| 突破形态 | close_position_20 ∈ [55%, 105%]，high_breakout_20 ∈ [-4%, 12%]，price_vs_ma20 ∈ [-3%, 10%] |
| 中期牛趋势 | ma_bull_20_60 ≥ 0（MA20 > MA60） |
| 活跃形态 | amount_ratio_3_20 ∈ [1.05, 3.5]，amount_ratio_5_20 ∈ [0.95, 3.0]，turnover_5 ∈ [1.5%, 18%] |
| 资金同步 | money_flow_bias_20 ≥ 5%，price_volume_sync_10 ≥ 0 |
| 风险控制 | vol_20 ≤ 8%，max_drawdown_20 ≥ -18%，upper_shadow_5 ≤ 42% |

### 尾盘版过滤阈值（更严格）

| 过滤项 | 条件（与盘后版的差异） |
|--------|---------------------|
| 当日行情 | change_rate ∈ [**+0.5%**, 8.5%]（必须上涨），amp ≤ 15% |
| 启动窗口 | ret_3 ∈ [**0%**, 10%]，ret_5 ∈ [**0%**, 15%]，accel ≥ **0%**（必须正加速） |
| 突破形态 | close_position_20 ∈ [**60%**, 105%]，price_vs_ma20 ∈ [**0%**, 8%]（必须站上均线） |
| 活跃形态 | **amount_ratio_1_20 ≥ 1.20**（当日量能必须放大），turnover_5 ∈ [2%, 18%] |
| 资金同步 | money_flow_bias_20 ≥ **10%** |
| 风险控制 | vol_20 ≤ **7.5%**，max_drawdown_20 ≥ **-16%**，upper_shadow_5 ≤ **38%** |

## 七、降级机制

| 场景 | 处理 |
|------|------|
| 个股 K 线不可用 | 用当日行情字段（涨幅、换手、成交额）做代理估算，标记 `kline_fallback_used = true` |
| 盘中快照不可用（尾盘版） | 默认抛错中止；设置环境变量 `SHORT_TAIL_ALLOW_DAILY_FALLBACK=1` 可降级至日线口径，并在汇总中记录 |
| 真实 K 线样本为空 | 退回纯行情降级候选，标记 `quote_only_fallback_used = true`，实盘优先级低 |

## 八、与主流多因子模型的对比

### 8.1 横向对比表

| 维度 | **本模型** | Fama-French 五因子 | Barra/MSCI GEM | 国内量化平台（聚宽/米筐常用） |
|------|-----------|-------------------|----------------|---------------------------|
| **设计目标** | 短线轮动（T+0~T+3） | 学术归因，解释截面收益 | 组合风险管理 | 月度/周度轮动，绩效归因 |
| **持仓周期** | 2~3 个交易日 | 月度再平衡 | 月度再平衡 | 月度/周度 |
| **核心信号** | 动量 + 量价结构 | 规模 SMB、价值 HML、盈利 RMW、投资 CMA | 多维风险暴露度 | 动量、价值、质量、低波 |
| **因子标准化** | 行业内 z-score + Winsorize | 全市场中位数分组 | 行业中性 + 市值中性 | 因子库截面标准化 |
| **交易过滤** | **7 项硬约束（量价 + 风控）** | 无 | 无（由组合优化控制） | 通常无 |
| **启动加速度** | ✅ `accel` 因子 | ❌ | ❌ | 部分有（rsi/macd 类） |
| `ma_bull_20_60` | ✅ 中期趋势确认 | ❌ | ❌ | 部分有 |
| **量价同步** | ✅ `money_flow_bias_20`、`price_volume_sync_10` | ❌ | ❌ | 少见 |
| **底部筹码收敛** | ✅ `chip_tightness_20` | ❌ | ❌ | 少见 |
| **科创板** | ❌ 排除 | 通常含 | 通常含 | 可选 |
| **数据来源** | Tushare / AkShare 日线 | CRSP / Compustat | MSCI 自有数据 | 聚宽/米筐本地数据 |
| **权重可配置** | ✅ `config.toml` | ❌ | ❌ | ❌（通常代码写死） |

### 8.2 核心设计取舍

**与 Fama-French 的差异**

Fama-French 模型以"解释历史收益来源"为目的，因子（市值/价值/盈利）更新频率为月度，不包含任何交易执行约束。本模型将多个月度因子替换为日线量价结构（`accel`、`money_flow_bias`、`chip_tightness`），并增加交易过滤层，以牺牲理论正交性换取高频可执行性。

**与 Barra 的差异**

Barra 类模型核心是风险模型，目标是最小化组合残差风险，适合管理大规模基金。本模型无仓位优化，直接输出 Top5 等权买入，适合个人短线操作。

**与聚宽/米筐常用因子库的差异**

量化平台默认提供月度截面因子，缺少"启动加速"这一短线核心信号，也缺少当日量能爆发的实时量比因子。本模型针对 T+2~T+3 周期加入了这些特有因子，但相应地不适合月度轮动。

## 九、模型局限性

1. **K 线覆盖率**：动态候选规模限 600~900 只，覆盖全 A 约 15%~20%，高流动性标的优先被采样，小盘/低流动性股票可能遗漏
2. **数据延迟**：依赖 Tushare / AkShare 接口，可能存在 1~5 分钟延迟；盘中快照用于尾盘版，若接口延迟大则降级为日线
3. **行业样本不足**：部分冷门行业样本 < 3 只时退化为全市场 z-score，行业中性效果下降
4. **短线噪声**：T+2~T+3 持有窗口较短，单次事件（公告、板块轮动）对结果影响大，回测夏普比不稳定
5. **科创板排除**：科创板高波动标的未纳入，对应机会缺失
